## 1. REFERENCIA INTERNA DEL SISTEMA

> Esta sección es el contexto técnico real que el redactor IA debe conocer antes de escribir cualquier contenido.

### Módulos activos en Controla IA

| Módulo | Función principal | Dato clave |
|---|---|---|
| **Dashboard** | Vista general de salud financiera | Muestra ingresos, gastos, saldo neto, ratio gastos/ingresos, tasa de ahorro, fondo de emergencia, flujo de caja proyectado y patrimonio neto |
| **Bot IA (WhatsApp)** | Registro de transacciones por mensaje de texto | El usuario escribe "Gasté 120.000 en supermercado" y la IA lo registra automáticamente |
| **Cuentas** | Gestión de cuentas bancarias y efectivo | Saldo consolidado, múltiples cuentas, cuenta corriente, inversiones, efectivo |
| **Tarjetas** | Control de tarjetas de crédito/débito | Seguimiento de gastos por tarjeta |
| **Ingresos** | Registro de entradas de dinero | Ingresos fijos y variables, sueldo, freelance, alquileres |
| **Gastos** | Registro de egresos | Categorización automática con IA, gastos fijos y variables |
| **Fijos** | Piloto automático de gastos/ingresos recurrentes | Alquiler, luz, internet — se cargan una vez y se repiten automáticamente |
| **Transacciones** | Historial completo | Filtros por fecha, categoría, cuenta, monto |
| **Categorías** | Organización de movimientos | Personalizables: Alimentación, Transporte, Salud, Educación, etc. |
| **Cuentas a cobrar** | Cobros pendientes | Clientes, fechas de vencimiento, seguimiento |
| **Deudas** | Control de deudas | Montos, plazos, tasas de interés |
| **Inversiones** | Portfolio de inversiones | Activos, rendimientos, cobros programados |
| **Análisis IA** | Insights automáticos | La IA analiza patrones, detecta gastos anómalos y da recomendaciones |
| **Reportes** | Análisis detallado | Evolución mensual, gastos por categoría, comparativas |
| **Metas** | Objetivos financieros | Definición de meta + plazo → el sistema calcula el aporte diario/semanal/mensual necesario |
| **Mercado** | Lista de compras e inventario de despensa | Evita compras duplicadas, lista inteligente, control de stock |
| **Vehículos** | Mantenimiento de autos | Historial, recordatorios de servicio, gastos por vehículo |
| **Personal / Negocios** | Separación de finanzas | Dos perfiles independientes en el mismo sistema |

### Flujo de carga de datos (cómo el usuario registra su información)

**Método 1 — Manual:**
1. El usuario va al módulo correspondiente (Gastos, Ingresos, etc.)
2. Toca "+ Agregar" o "+ Nuevo"
3. Completa: monto, categoría, cuenta, fecha y descripción opcional
4. El Dashboard se actualiza en tiempo real

**Método 2 — Bot IA por WhatsApp:**
1. El usuario guarda el número de WhatsApp de Controla IA
2. Envía un mensaje en lenguaje natural: "Gasté 50 en combustible", "Cobré el sueldo 1.500"
3. La IA procesa el mensaje, identifica tipo (gasto/ingreso), monto y categoría
4. Responde confirmando el registro con resumen del saldo actual
5. Todo queda registrado en el Dashboard automáticamente

**Método 3 — Escaneo de tickets con IA:**
1. El usuario saca una foto al comprobante/factura
2. La IA lee el monto total y la categoría
3. El gasto se pre-completa para que el usuario solo confirme

**Método 4 — Fijos automáticos:**
1. En el módulo "Fijos", el usuario carga sus gastos recurrentes (alquiler, luz, Netflix)
2. Configura monto, frecuencia y cuenta de débito
3. El sistema los registra automáticamente cada mes y avisa antes de que venzan

## 2. AUDIENCIA TARGET

**Perfil primario:**
- Asalariados de Latinoamérica entre 22-45 años
- Ingresos: USD 300 - USD 2.000/mes
- Problema principal: llegan al fin del mes sin saber en qué gastaron
- No tienen educación financiera formal
- Usan WhatsApp todos los días
- Quieren ahorrar pero no saben cómo empezar

**Perfil secundario:**
- Emprendedores y freelancers que mezclan finanzas personales y del negocio
- Necesitan separar y controlar ambos flujos

### PIEZA 1 — EBOOK
## "Finanzas Personales para Asalariados"
*Subtítulo: El método para hacer rendir tu sueldo y construir libertad financiera*

**Formato:** PDF, 20-30 páginas  
**Tono:** Cercano, directo, sin jerga financiera. Como un amigo que sabe de finanzas.  
**Objetivo:** Enseñar el método completo para ordenar las finanzas de un asalariado, usando Controla IA como herramienta central.

#### Estructura de capítulos

**Capítulo 1 — Por qué siempre llegás en cero**
- El ciclo de "cobrar y gastar"
- Los 3 tipos de fugas: hormiga, invisible y estructural
- Por qué la fuerza de voluntad no funciona sin sistema
- *Conexión con el sistema:* mostrar cómo el Dashboard revela las fugas por primera vez

**Capítulo 2 — Tu primera semana con Controla IA**
- Cómo crear tu cuenta y configurar el perfil Personal
- Paso a paso: cargar tus cuentas bancarias
- Cargar tu sueldo como ingreso fijo
- Cargar tus gastos fijos (alquiler, servicios, cuotas)
- *Módulos clave:* Cuentas, Fijos, Ingresos

**Capítulo 3 — El hábito de los 3 minutos diarios**
- Cómo registrar gastos del día con WhatsApp Bot o manual
- La regla: registrar antes de cerrar los ojos
- *Módulos clave:* Bot IA WhatsApp, Gastos, Transacciones

**Capítulo 4 — Entender tu dinero por primera vez**
- Cómo leer el Dashboard
- Qué es el ratio gastos/ingresos y cuál debería ser el tuyo
- Qué es la tasa de ahorro y cómo mejorarla
- El flujo de caja proyectado: saber hoy cuánto tendrás en 30 días
- *Módulos clave:* Dashboard, Reportes, Análisis IA

**Capítulo 5 — El sistema de los 3 sobres digitales**
- Sobre 1: Gastos fijos (categorías no negociables)
- Sobre 2: Gastos variables (límite mensual por categoría)
- Sobre 3: Ahorro y metas
- Cómo configurarlo en Controla IA con categorías
- *Módulos clave:* Categorías, Metas, Dashboard

**Capítulo 6 — Tu primera meta real**
- Cómo definir una meta SMART con Controla IA
- El sistema de aporte diario: "si guardás lo que cuesta una gaseosa por día..."
- Progreso visible: ver la barra avanzar cada semana
- *Módulos clave:* Metas

**Capítulo 7 — Checklist del primer mes**
- Lista de verificación para los primeros 30 días
- Qué revisar cada semana
- Señales de que el sistema está funcionando

### PIEZA 2 — GUÍA COMPLETA
## "Cómo dejar de vivir al día"
*Subtítulo: El sistema simple para ordenar tus finanzas y ahorrar desde este mes*

**Formato:** PDF, 12-18 páginas  
**Tono:** Urgente, motivador, orientado a la acción inmediata  
**Objetivo:** Guía de acción rápida. El usuario tiene que poder leerla en 30 minutos y empezar a usarla hoy.

#### Estructura

**Parte 1 — Diagnóstico (15 minutos)**
- Test rápido: ¿estás viviendo al día? (5 preguntas con puntaje)
- Calculá tu "número de supervivencia" (cuánto necesitás para el mes)
- Identificá tus 3 principales fugas de dinero
- *Acción práctica:* abrir Controla IA y revisar Reportes → Gastos por categoría del último mes

**Parte 2 — El plan de emergencia de 7 días**
- Día 1: Configurar cuentas y saldo inicial
- Día 2: Registrar todos los gastos fijos del mes
- Día 3: Activar el Bot de WhatsApp para gastos diarios
- Día 4: Revisar el Dashboard y entender el ratio
- Día 5: Identificar 3 gastos que podés eliminar o reducir
- Día 6: Crear tu primera meta de ahorro (aunque sea pequeña)
- Día 7: Configurar el flujo de caja proyectado y ver tu futuro financiero
- *Módulos clave:* todos los módulos base

**Parte 3 — El sistema de los 2 bolsillos**
- Bolsillo 1: Lo que ya comprometiste (fijos + deudas)
- Bolsillo 2: Lo que podés decidir libremente
- Cómo visualizarlo en el Dashboard en tiempo real
- *Módulos clave:* Dashboard, Fijos, Deudas

**Parte 4 — Mantenerlo en piloto automático**
- Automatizar los fijos para no olvidarse
- Configurar alertas de saldo mínimo
- Usar el Análisis IA para detectar desvíos
- *Módulos clave:* Fijos, Análisis IA, Bot WhatsApp

### PIEZA 3 — GUÍA PRÁCTICA
## "Finanzas para tu Negocio"
*Subtítulo: Separás tus finanzas personales y de tu negocio como un profesional*

**Formato:** PDF, 15-20 páginas  
**Tono:** Profesional pero simple. Para el emprendedor que no tiene contador.  
**Objetivo:** Enseñar a separar y gestionar finanzas personales y del negocio en el mismo sistema.

#### Estructura

**Capítulo 1 — El error que cometen el 90% de los emprendedores**
- Mezclar finanzas personales y del negocio
- Por qué esto destruye la claridad financiera
- La solución: dos perfiles, un sistema
- *Acción:* activar el perfil "Negocios" en Controla IA

**Capítulo 2 — Configurar el perfil de tu negocio**
- Crear cuentas separadas para el negocio
- Definir categorías de ingresos del negocio (ventas, servicios, etc.)
- Definir categorías de gastos del negocio (proveedores, marketing, nómina, etc.)
- Cargar los gastos fijos del negocio
- *Módulos clave:* Cuentas, Categorías, Fijos (perfil Negocios)

**Capítulo 3 — El sueldo del dueño**
- Cómo pagarte a vos mismo de forma ordenada
- Separar el dinero del negocio del dinero personal
- Transferencia del perfil Negocio al perfil Personal
- *Módulos clave:* Ingresos (Personal), Transacciones (Negocios)

**Capítulo 4 — Flujo de caja del negocio**
- Cómo proyectar ingresos y gastos del próximo mes
- Cobros pendientes de clientes: cómo registrarlos y hacer seguimiento
- Deudas con proveedores: control y fechas de vencimiento
- *Módulos clave:* Cuentas a cobrar, Deudas, Dashboard (Negocios)

**Capítulo 5 — Los reportes que todo emprendedor necesita**
- Reporte mensual: ingresos vs gastos del negocio
- Reporte de rentabilidad por categoría
- Cómo preparar información para el contador usando los reportes de Controla IA
- *Módulos clave:* Reportes, Análisis IA

**Capítulo 6 — KPIs básicos para tu negocio**
- Margen de ganancia
- Gastos fijos vs variables
- Punto de equilibrio mensual
- Cómo calcularlos con los datos de Controla IA

### PIEZA 4 — GUÍA RÁPIDA
## "Automatizá tus finanzas con WhatsApp"
*Subtítulo: Registrá gastos, ingresos y recibí reportes con la ayuda de la IA*

**Formato:** PDF visual, 6-10 páginas (guía paso a paso con capturas)  
**Tono:** Super simple, visual, orientado a la acción en 5 minutos  
**Objetivo:** Onboarding rápido del Bot de WhatsApp. El usuario debe poder activarlo y usarlo en menos de 10 minutos.

#### Estructura

**Paso 1 — Activar el Bot en tu cuenta**
- Dónde encontrar el número de WhatsApp del Bot en la app
- Cómo guardar el contacto en tu teléfono
- Enviar el primer mensaje de activación
- *Captura sugerida:* pantalla de configuración del Bot + chat de WhatsApp inicial

**Paso 2 — Los comandos básicos**
- Registrar un gasto: "Gasté [monto] en [concepto]"
  - Ejemplo: "Gasté 50 en almuerzo", "Gasté 200 en supermercado"
- Registrar un ingreso: "Cobré [monto] por [concepto]"
  - Ejemplo: "Cobré 1.500 de sueldo", "Cobré 300 de freelance"
- Consultar saldo: "¿Cuánto tengo?" o "Mi saldo"
- Consultar gastos del mes: "¿Cuánto gasté este mes?"
- Resumen financiero: "Resumen"
- *Captura sugerida:* conversación de WhatsApp con respuestas del Bot

**Paso 3 — Cómo la IA categoriza automáticamente**
- La IA detecta la categoría según el concepto
- "Almuerzo" → Alimentación
- "Nafta" o "combustible" → Transporte
- "Netflix" → Entretenimiento / Suscripciones
- Cómo corregir una categoría si la IA se equivoca
- *Módulos clave:* Categorías, Transacciones

**Paso 4 — El hábito WhatsApp que cambia todo**
- Cuándo registrar: en el momento de pagar (1 mensaje = 5 segundos)
- Configurar recordatorio diario a las 21hs para revisar los gastos del día
- Cómo usar el historial del chat como control adicional

**Paso 5 — Reportes por WhatsApp**
- Recibir el resumen semanal automático
- Alertas cuando superás el límite de una categoría
- Notificación cuando una meta llega al 50% / 100%

**Casos de uso reales**
- María que registra cada compra del super mientras espera en la caja
- José que anota el combustible apenas llena el tanque
- Ana que cobra a clientes y lo registra desde WhatsApp antes de colgar

### PIEZA 5 — CHECKLIST

*Subtítulo: Tu rutina de 15 minutos para cerrar el mes con control total*

**Formato:** PDF de 1-2 páginas, diseño visual para imprimir o guardar  
**Tono:** Práctico, listo para usar

#### Contenido del Checklist

**SEMANA 1 — Arranque del mes**

- [ ] Revisar el saldo inicial de cada cuenta
- [ ] Confirmar el ingreso del sueldo/cobro principal
- [ ] Revisar cobros pendientes del mes anterior
- *Módulos:* Fijos, Cuentas, Ingresos, Cuentas a cobrar

**SEMANA 2 — Control intermedio**
- [ ] Revisar el ratio gastos/ingresos en el Dashboard
- [ ] Verificar que ninguna categoría superó el 80% del límite mensual
- [ ] Actualizar el avance de metas activas

**SEMANA 3 — Ajuste**
- [ ] Revisar el flujo de caja proyectado para fin de mes
- [ ] Si el flujo es negativo: identificar 1-2 gastos que se pueden diferir

**CIERRE DE MES — Análisis**
- [ ] Revisar el Reporte mensual completo
- [ ] Comparar gastos reales vs gastos estimados
- [ ] Calcular cuánto se ahorró efectivamente
- [ ] Hacer un aporte a la meta principal del mes
- [ ] Revisar los insights del Análisis IA
- [ ] Anotar 1 aprendizaje financiero del mes (en notas del sistema)
- *Módulos:* Reportes, Metas, Análisis IA

**BONUS — Revisión trimestral (cada 3 meses)**
- [ ] Revisar el Patrimonio Neto: ¿creció?
- [ ] Evaluar si las metas activas siguen siendo relevantes
- [ ] Revisar inversiones y rendimientos
- [ ] Analizar tendencias de 3 meses en Reportes
- *Módulos:* Dashboard (Patrimonio neto), Metas, Inversiones, Reportes

## 4. INSTRUCCIONES PARA EL REDACTOR IA

### Reglas de estilo
1. **Siempre en español latinoamericano** — usar "vos" y no "tú" en las guías para Argentina/Paraguay/Uruguay; adaptar a "tú" para México/Colombia/Perú
2. **Frases cortas** — máximo 25 palabras por oración
3. **Sin jerga financiera** — si se usa un término técnico (ej: "flujo de caja"), explicarlo con una metáfora cotidiana
4. **Siempre cerrar con acción** — cada sección termina con "Ahora hacé esto en Controla IA: [instrucción específica]"
5. **Incluir números reales** — usar ejemplos con montos concretos ($200, $50, etc.)

### Relación con el sistema
- Cada vez que se mencione una funcionalidad, indicar el nombre exacto del módulo
- Incluir al menos 1 "captura sugerida" por capítulo describiendo qué pantalla de la app mostrar
- El sistema siempre se menciona como **Controla IA**, nunca "la app" o "el software"

### Lo que NO debe aparecer
- Consejos de inversión arriesgados
- Promesas de ingresos garantizados
- Comparaciones con competidores
- Lenguaje técnico contable
